# SAP R/3 Job

**Section:** [[Job-Types-MOC]] · **Parent:** [[Enterprise-Resource-Planning-Jobs]]

An SAP R/3 job lets you create and execute a new SAP job, copy an existing job, execute a predefined job, monitor a scheduled job, execute a batch input session, activate or deactivate an SAP profile, and trigger or watch for an SAP event. This job connects to the SAP Application Server or SAP Message Server, depending on the Connection Profile settings.

> [!note] Note
BMC recommends that you only run up to 100 SAP jobs concurrently per Agent. You can configure Agent restrictions as described in [[Agent-(Host)-Restrictions]].

To create an SAP R/3 job, see [[Creating-a-Job]]. For more information about this plug-in, see [[Control-M-for-SAP|Control-M for SAP]].
