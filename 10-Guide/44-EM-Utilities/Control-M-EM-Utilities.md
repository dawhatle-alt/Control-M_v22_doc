# Control-M/EM Utilities

**Section:** [[EM-Utilities-MOC]]

The following table lists the utilities that enable you to manage and configure Control-M/EM.

| Utility | Description |
|---|---|
| [[cli-Utility|cli]] | Enables you to perform various operations from a command line for the management of jobs, folders, calendars, and Workload Policies. |
| [[ctl]] | Checks if Control-M/EM Server components are operational and sends commands. |
| [[services-cli]] | Enables you stop, start and send commands to services. |
| [[emsca]] | Enables you to monitor services through system wide commands that are not dependent on any other service. |
| [[emcha-restore|emcha -restore]] | Restores high availability data to the primary or secondary Control-M/EM host. |
| [[erase_audit_data]] | Deletes records written prior to the specified date. |
| [[purge_xalerts]] | Deletes exception alerts from the Exception Alerts table in the Control-M/EM database. |
| [[purge_runinfo]] | Enables you to clean out run information retained by Control-M/Forecast for the purposes of performing its calculations. |
| [[db_check_space]] | Provides information about Control-M/EM databases that use Oracle database servers. |
| [[em_database_menu]] | Facilitates day-to-day maintenance and diagnostics of Control-M/EM database running with PostgreSQL, Oracle, and MSSQL databases. |
| [[arc_database_menu]] | Facilitates day-to-day maintenance and diagnostics of Control-M Workload Archiving running with a PostgreSQL database. |
| [[em_rebuild_database]] | Enables you to rebuild the Control-M/EM database in the specified PostgreSQL server database. |
| [[SQL-and-em_SQL]] | Enables you to connect to the database from the command line. |
| [[loader]] | Enables you to load default data to the Control-M/EM database. |
| [[sweep]] | Deletes jobs that are no longer active from the Control-M/EM and Control-M/Server databases. |
| [[util]] | Enables you to perform the certain database related functions. |
| [[Control-M-EM-Host-Configurations|em-configure-db]] | Enables you to reconfigure the database server connection data in various situations. |
| [[Control-M-EM-Host-Configurations|em-configure-hostname]] | Enables you to update host name configuration in various situations. |
| [[Control-M-EM-Host-Configurations#Control-M/EM Web URL Configuration|em-configure-endpoint]] | Enables you to update the web URL for Control-M/EM. |
| [[Control-M-EM-Host-Configurations#Control-M/Server Hostname Update|em-reconfigure-ctm- host]] | Enables you to associate Control-M/EM with a new Control-M/Server hostname. |
| [[Control-M-EM-Host-Configurations#Secondary High Availability Environment Removal|em-remove-secondary]] | Enables you to update Control-M/EM configuration after you uninstall a secondary High Availability Control-M/EM installation environment. |
| [[Control-M-EM-Host-Configurations#Distributed Environment Removal|em-remove-distributed]] | Enables you to update Control-M/EM configuration after you uninstall a distributed Control-M/EM installation environment. |
| [[emcryptocli]] | Generates an encrypted version of your new password. |
| [[root_menu]] | Enables you to access functions and utilities that are used to maintain Control-M/EM. |
| [[check_config]] | Checks properties and settings in Control-M/EM and notifies you whether values are suitable for the size of your production environment. Also enables you to adjust values according to recommendations and to revert changes. |
