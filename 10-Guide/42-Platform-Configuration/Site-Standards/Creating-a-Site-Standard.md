# Creating a Site Standard

**Section:** [[Platform-Configuration-MOC]] · **Parent:** [[Site-Standards]]

This procedure describes how to create a site standard, which enables you to define rules and apply them to job definitions.

### Begin

1. From the Tools drop-down list, select Site Standards. The Site Standards page appears.
2. From the Site Standards toolbar, click Add Site Standard. The Create New Site Standard pane appears.
3. Do the following:

a. In the Name field, type a name for the site standard. b. In the Description field, type a description of the site standard.

4. Click Create. An empty site standard appears.
5. From the Site Standards toolbar, select from one or more of the following to create restriction rules:
- Rule: See [[Creating-a-Site-Standard-Rule]].
- Business Parameters: See [[Adding-a-Business-Parameter-to-a-Site-Standard]].
- Internal Rules: See [[Adding-an-Internal-Rule-to-a-Site-Standard]].
- Event Format: See [[Event-Format]] or [[Defining-the-Event-Format]].
6. From the Site Standard toolbar, click Save. The site standard is created and appears on the site standard list.
