# Control-M/Server Communication Status

**Section:** [[Monitoring-MOC]]

The Server Communication Status tool enables you to monitor Control-M/Server communications and settings without administrative privileges.

The following table describes the informational columns in the Servers Communication Status grid.

| Column Name | Description |
|---|---|
| Server | Shows the name of Control-M/Server or Control-M for z/OS set in the Configuration domain. |
| Status | Shows the communication status of Control-M/Server in the Control-M environment.. |
| Enabled | Indicates whether Control-M/EM recognizes Control-M/Server. |
| Communication | Indicates if an error is identified in the communication route between Control-M/Server and Control-M/EM. |
| Synchronized | Shows the latest synchronization time between the Agent and Control-M/Server and indicates whether the synchronization was successful. |
| Message | Shows details about the Control-M/Server network status. |
| New Day Time | Shows when the New Day procedure is performed on Control-M/Server. |
| Start Day | Shows the first day of the business week. |
| Time Zone | Shows the time zone of Control-M/Server, including the DST information. |
| Platform | Shows the operating system that Control-M/Server is installed on. |
| Folders Sync | Shows the date and time of the last folder synchronization with Control-M/Server and indicates whether the synchronization was successful. |
| Calendar Sync | Shows the date and time of the last calendar synchronization with Control-M/Server and indicates whether the synchronization was successful. |
| Workload Policies Sync | Shows the date and time of the latest synchronization of the Workload Policies with Control-M/Server and indicates whether the synchronization was successful. |
