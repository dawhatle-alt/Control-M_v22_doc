# startdb

**Section:** [[Server-Utilities-MOC]]

The startdb utility starts the SQL database server.

> [!note] Note
You can also start the SQL database from the [[ctm_menu]] utility.

## Starting the SQL Database Server with the startdb Utility

This procedure describes how to start the SQL database server with the startdb utility.

### Before You Begin

- Verify that the SQL Database Server is started before you start Control-M/Server and that the SQL Database Server is active as long as Control-M/Server is active.

### Begin

1. Do one of the following:
- UNIX: Log in to a Control-M/Server account
- Windows: Open a command prompt where Control-M/Server is installed.
2. Run the following command: startdb The SQL Database Server starts up.
