# show_ca

**Section:** [[Server-Utilities-MOC]]

The show_ca utility displays the status of Control-M/Server Configuration Agent.

## Viewing Control-M/Server Configuration Agent Status with the show_ca Utility

This procedure describes how to view the status of the Control-M/Server Configuration Agent with the show_ca utility.

### Begin

1. Do one of the following:
- UNIX: Log in to a Control-M/Server account
- Windows: Open a command prompt where Control-M/Server is installed.
2. Run the following command: show_ca The Control-M/Server Configuration Agent status and port number appears.
