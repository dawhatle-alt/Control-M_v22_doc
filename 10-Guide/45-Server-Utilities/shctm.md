# shctm

**Section:** [[Server-Utilities-MOC]]

The shctm utility displays the processes that are currently running on a Control-M/Server.

## Viewing the Active Processes on a Control-M/Server

This procedure describes how to the processes that are currently running on a Control-M/Server with the shctm utility.

### Begin

1. Do one of the following:
- UNIX: Log in to a Control-M/Server account
- Windows: Open a command prompt where Control-M/Server is installed.
2. Run the following command: shctm The process IDs (PIDs) and filenames of the active processes on Control-M/Server appear.
