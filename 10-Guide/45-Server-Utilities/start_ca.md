# start_ca

**Section:** [[Server-Utilities-MOC]]

The start_ca utility starts the Control-M/Server Configuration Agent.

> [!note] Note
You can also start the Control-M/Server Configuration Agent from the [[ctm_menu]] utility.

## Starting Control-M/Server Configuration Agent with the start_ca Utility

This procedure describes how to start up the Control-M/Server Configuration Agent with the start_ca utility.

### Begin

1. Do one of the following:
- UNIX: Log in to a Control-M/Server account.
- Windows: Open a command prompt where Control-M/Server is installed.
2. Run the following command: start_ca A message similar to the following is displayed: Starting Control-M/Server Configuration Agent at Fri Jun 4 14:31:27 IDT 2021
