# dbversion

**Section:** [[Server-Utilities-MOC]]

The dbversion utility retrieves the database server version and tests the connectivity of the Control-M/Server database, which can be any of the following:

- Oracle
- MSSQL
- PostgreSQL

## Running the dbversion Utility

This procedure describes how to run the dbversion utility, which retrieves the database server version and tests the Control-M/Server database connectivity.

### Begin

1. Do one of the following:
- UNIX: Log in to a Control-M/Server account
- Windows: Open a command prompt window where Control-M/Server is installed.
2. Enter the following command: dbversion The Control-M/Server database type and version appears.
