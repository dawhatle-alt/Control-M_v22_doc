# start_ctm

**Section:** [[Server-Utilities-MOC]]

The start_ctm utility starts Control-M/Server.

> [!note] Note
You can also start Control-M/Server from the [[ctm_menu]] utility.

## Starting Control-M/Server with the start_ctm Utility

This procedure describes how to start the Control-M/Server with the start_ctm utility

### Begin

1. Do one of the following:
- UNIX: Log in to a Control-M/Server account.
- Windows: Open a command prompt where Control-M/Server is installed.
2. Run the following command: start_ctm The Control-M/Server starts up.
