# shut_ctm

**Section:** [[Server-Utilities-MOC]]

The shut_ctm utility shuts down Control-M/Server and its processes.

> [!note] Note
You can also shut down the Control-M/Server from the [[ctm_menu]] utility.

## Shutting Down Control-M/Server with the shut_ctm Utility

This procedure describes how to shut down Control-M/Server and its processes with the shut_ctm utility.

### Begin

1. Do one of the following:
- UNIX: Log in to a Control-M/Server account.
- Windows: Open a command prompt where Control-M/Server is installed.
2. Run the following command: shut_ctm The Control-M/Server shuts down.
