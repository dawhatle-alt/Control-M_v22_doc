# shut_ca

**Section:** [[Server-Utilities-MOC]]

The shut_ca utility shuts down the Control-M/Server Configuration Agent.

> [!note] Note
You can also shut down the Control-M/Server Configuration Agent from the [[ctm_menu]] utility.

## Shutting Down Control-M/Server Configuration Agent with the shut_ca Utility

This procedure describes how to shut down the Control-M/Server Configuration Agent with the shut_ca utility.

### Begin

1. Do one of the following:
- UNIX: Log in to a Control-M/Server account.
- Windows: Open a command prompt where Control-M/Server is installed.
2. Run the following command: shut_ca The following message appears: --------------------------------------------------- Shutting down Control-M/Server Configuration Agent --------------------------------------------------- Waiting..... Control-M/Server Configuration Agent is down
