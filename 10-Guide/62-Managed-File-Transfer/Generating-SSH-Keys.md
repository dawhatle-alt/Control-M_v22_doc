# Generating SSH Keys

**Section:** [[Managed-File-Transfer-MOC]]

This procedure describes how to generate an SSH private and public keys in the Configuration domain, which enables the SFTP client to authenticate itself to the SFTP server instead of using a password. After the keys are generated, you need to send the public key to the SFTP server administrator to activate public key authentication.

### Begin

1. From the icon, select Configuration. The Configuration domain opens.
2. From the drop-down list, select Plug-ins. The Plug-ins page appears.
3. In the Plug-ins area, click the three dots on the File Transfer plug-in and then select File Transfer Plugins.
4. From the Configuration drop-down list, select Generate SSH Key. The Generate SSH Key pane appears.
5. In the Key Name field, type the name for the private and public keys.
6. In the Key Passphrase area, type the password of the private key file.
7. In the Key Algorithm drop-down list, select one of the following key algorithm options:
- RSA
- ECDSA
8. In the Key Length drop-down list, select one of the following key length options:
- RSA:
  - 1024
  - 2048 (default)
  - 3072
  - 4096
- ECDSA
  - 128 (default)
  - 256
  - 521
9. Click Save. The public and private keys are generated and saved on the Agent host in the following directory: \<Control-M/Agent_Home_Dir>\cm\AFT\data\Keys NOTE: Generated keys defined with larger bits provides more security. However, you might receive a timeout message if generated on a slower host. Verify that the keys were generated by checking the above location.
10. To save the public key locally, click Yes. The key is saved on your host.
11. Add the public key value to the remote SFTP server authorized_keys file, as described in [[File-Transfer-Server#Connecting to the SFTP Server with Public Key Authentication|Connecting to the SFTP Server with Public Key Authentication]].
12. To use key authentication in a File Transfer Job, use the private key name and define the passphrase in a connection profile.
