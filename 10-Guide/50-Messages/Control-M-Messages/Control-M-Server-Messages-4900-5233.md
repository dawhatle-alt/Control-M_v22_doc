The CYCLIC_RERUN parameter in the Control-M/Server configuration determines whether a cyclic job or SMART folder should rerun if that job or SMART folder ends NOTOK. The job or SMART folder state changes to post-processed and does not rerun. | No action is required. |
| 5232 Warning: Cyclic job getting close to maximum allowed runs. | Control-M/Server verifies that the job or SMART folder recount has not crossed the default hard limit, which is 99900. A warning issues when the hard limit reaches 90%. | Increase the hard limit value by changing the parameter RERUN_HARD_LIMIT in config.dat with a higher value. |
| 5233 Error: cyclic job run too many times and will not run any more | When the job or SMART folder rerun count reaches the hard limit, the job or SMART folder stops. The default hard limit value is set at 99900. | Increase the rerun hard limit by changing the parameter RERUN_HARD_LIMIT in config.dat with a higher value. |
