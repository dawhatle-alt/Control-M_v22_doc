# Control-M/EM Messages

**Section:** [[Messages-MOC]] · **Parent:** [[Control-M-Messages]]

The following Control-M/EM messages are listed according to their ID number. The messages range from warning messages to error messages and contain an explanation and corrective action (where possible).

Messages are split into ranges of ~80 IDs. Search the ID to find the right range.
