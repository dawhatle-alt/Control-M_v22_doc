# Keyboard Shortcuts

**Section:** [[Getting-Started-MOC]]

You can use the following keyboard shortcuts for quick access to Control-M functions.

- [[Keyboard-Shortcuts#General|General]]
- [[Keyboard-Shortcuts#Planning Domain|Planning Domain]]
- [[Keyboard-Shortcuts#Monitoring Domain|Monitoring Domain]]
- [[Keyboard-Shortcuts#Forecast Domain|Forecast Domain]]

## General

The following table describes general keyboard shortcuts.

| Shortcut | Function |
|---|---|
| Shift + Arrows | Move between domains. |
| Tab | Move to next element. |
| Arrows | Navigate in table. |
| Ctrl + Shift + Y | Focus on domains. |
| Ctrl + Shift + V | Focus on application settings. |

## Planning Domain

The following table describes the Planning domain keyboard shortcuts.

| Shortcut | Function |
|---|---|
| Ctrl + A | Select all objects. |
| Alt + R | Run a workspace. |
| Alt + S | Run selected jobs or folders. |
| Alt + X | Export a workspace to a JSON file. |
| Ctrl + J | Add a new folder or OS job (if a folder is selected). |
| Ctrl + E | Set event source. |
| Ctrl + Shift + E | Set event target. |
| Ctrl + Shift + F | Source on Ended not OK. |
| Ctrl + S | Save a workspace. |
| Alt + V | Validate a workspace. |
| Alt + B | Submit a workspace for review. |
| Alt + C | Check In a workspace. |
| Alt + D | Review and edit workspace details. |
| Shift + E | Expand all. |
| Shift + C | Collapse all. |
| Alt + L | Load folders or jobs. |
| Alt + U | Unload folders or jobs. |
| Ctrl + C | Copy selected jobs. |
| Ctrl + X | Cut selected jobs. |
| Ctrl + V | Paste selected jobs. |
| Alt + Ctrl + V | Paste copied jobs with their events. |
| Delete | Delete selected jobs. |
| Alt + Z | Rollback selected jobs. |
| Alt + G | Show in List View. |
| Alt + M | Show in Tile View. |
| Ctrl + F | Search in job properties. |
| Alt + N | Open neighborhood for selected entity. |
| Ctrl + 0 | Reset zoom to 100%. |
| Ctrl + + | ( Tile View mode only) Zoom in. |
| Ctrl + - | ( Tile View mode only) Zoom out. |
| Ctrl + Click | Select multiple entities. |
| Shift + Click | Select a range of consecutive workspaces in the Workspaces sub-tab in the Home tab. |
| Shift + Arrows | Navigate between sections. |
| Tab | Move to next element. |
| Ctrl + Shift + Y | Focus on domains. |
| Ctrl + Shift + V | Focus on application settings. |
| Ctrl + Shift + D | Focus on tabs. |
| Ctrl + Shift + Q | Focus on page actions. |
| Ctrl + Shift + B | Focus on bottom pane. |
| Ctrl + Shift + R | Focus on right pane. |
| Ctrl + Shift + L | Focus on left pane. |
| Ctrl + Shift + J | Focus on main table. |
