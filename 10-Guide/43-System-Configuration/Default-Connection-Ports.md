# Default Connection Ports

**Section:** [[System-Configuration-MOC]]

The following table lists the default ports for Control-M connections.

| Connection | Server Port |
|---|---|
| Listening http connector on the web server | 18080 |
| Listening https connector on the web server | 8443 |
| Listening port on the Control-M/Server for the gateway connection | 2370 |
| Listening port on the Control-M/Server for the CMS connection | 2369 |
| Listening port on the Control-M/Server for the Agent connection | 7005 |
| Listening port on the Agent for the Control-M/Server connection | 7006 |
| Kafka on the Control-M/Server | 19092 |
| Zookeeper on the Control-M/Server | 12181 |
